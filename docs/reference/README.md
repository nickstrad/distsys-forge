# Reference notes

Technical notes that outgrow a single lesson live here: error-handling conventions,
package boundaries, testing architecture, and similar cross-cutting material. These
documents are forward-looking guidance for the learner and the agents — not a
specification of current behavior, and not shown in the human-facing reader (which only
indexes `plans/`).

Start each note when a convention gets repeated across lessons; link to it from the
lessons instead of restating it.
